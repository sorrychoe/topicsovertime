# Package index

## about topicovertime

topicovertime fits the Topics over Time model of Wang and McCallum
(2006) in R.

- [`topicovertime`](https://sorrychoe.github.io/topicovertime/reference/topicovertime-package.md)
  [`topicovertime-package`](https://sorrychoe.github.io/topicovertime/reference/topicovertime-package.md)
  : topicovertime: Topics over Time: A Continuous-Time Topic Model

- [`tot()`](https://sorrychoe.github.io/topicovertime/reference/tot.md)
  : Fit a Topics over Time model

### post-estimation

- [`terms(`*`<tot>`*`)`](https://sorrychoe.github.io/topicovertime/reference/terms.tot.md)
  : Most probable words per topic
- [`topic_time()`](https://sorrychoe.github.io/topicovertime/reference/topic_time.md)
  : Topic proportions over time
- [`predict(`*`<tot>`*`)`](https://sorrychoe.github.io/topicovertime/reference/predict.tot.md)
  : Predict topics or timestamps for new documents
- [`plot(`*`<tot>`*`)`](https://sorrychoe.github.io/topicovertime/reference/plot.tot.md)
  : Plot topic trends or topic time densities
