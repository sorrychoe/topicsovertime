# Package index

## about topicsovertime

topicsovertime fits the Topics over Time model of Wang and McCallum
(2006) in R.

- [`topicsovertime`](https://sorrychoe.github.io/topicsovertime/reference/topicsovertime-package.md)
  [`topicsovertime-package`](https://sorrychoe.github.io/topicsovertime/reference/topicsovertime-package.md)
  : topicsovertime: Topics over Time: A Continuous-Time Topic Model

### model fitting

- [`tot()`](https://sorrychoe.github.io/topicsovertime/reference/tot.md)
  : Fit a Topics over Time model

- [`terms(`*`<tot>`*`)`](https://sorrychoe.github.io/topicsovertime/reference/terms.tot.md)
  : Most probable words per topic
- [`topic_time()`](https://sorrychoe.github.io/topicsovertime/reference/topic_time.md)
  : Topic proportions over time
- [`predict(`*`<tot>`*`)`](https://sorrychoe.github.io/topicsovertime/reference/predict.tot.md)
  : Predict topics or timestamps for new documents
- [`plot(`*`<tot>`*`)`](https://sorrychoe.github.io/topicsovertime/reference/plot.tot.md)
  : Plot topic trends or topic time densities
